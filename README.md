# 🇮🇳 Indian Startup Funding Analysis Dashboard

An interactive data analysis and visualization dashboard built using **Python and Streamlit** to explore investment patterns in the Indian startup ecosystem.

## 📌 Project Overview

This project analyzes an Indian Startup Funding dataset sourced from **Kaggle**.

The objective of this project is to explore startup investments and understand patterns related to:

- Investors
- Startups
- Industry verticals
- Cities
- Investment rounds
- Investment amounts
- Recent investments

After performing data cleaning and analysis, the insights were converted into an interactive **Streamlit dashboard**.

## 🎯 Objectives

- Analyze Indian startup funding data
- Understand investor investment patterns
- Identify startups receiving investments
- Explore different industry sectors
- Analyze investment rounds
- Compare investment amounts
- Create an interactive dashboard for data exploration

## 📊 Dashboard Features

### 🔹 Investor Analysis

Users can select an investor from the dashboard and explore their investment activity.

### 🔹 Most Recent Investments

Displays the most recent investments made by the selected investor, including:

- Date
- Startup
- Industry Vertical
- City
- Funding Round
- Investment Amount

### 🔹 Biggest Investments

Visualizes the largest investments associated with the selected investor.

### 🔹 Sector Analysis

Shows the industry sectors/verticals in which the selected investor has invested.

### 🔹 Interactive Filters

The dashboard allows users to select different investors and dynamically explore their investment information.

## 🗂️ Dataset

The dataset was obtained from **Kaggle** and contains information about funding rounds of Indian startups.

Important fields include:

- Date
- Startup Name
- Industry Vertical
- Sub-Vertical
- City Location
- Investors Name
- Investment Type
- Amount in USD
- Remarks

The dataset is useful for studying investment trends, startup sectors, cities and investor activity in India.
